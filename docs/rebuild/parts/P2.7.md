# P2.7 Content, SEO, PWA

## Audit (live www.himmat.store, 2026-10-09)

Pages: `/about`, `/contact`, `/privacy`, `/terms`, `/track-order`, `/offline`, 404; `robots.txt`, `sitemap.xml`, `manifest.json`, `sw.js`, page metadata.

**Made-up or contradictory content**
1. **About "أرقام تثق بها":** "years in market" falls back to a made-up **15** when no founding year is set. The other three are live counts (products, customers with orders, delivered orders), which are small on a new store and look bad. All four render as **0** until scrolled into view (no-JS and crawlers see 0).
2. **Opening hours contradict each other.** Contact heading says "الأحد - الخميس، ٨ صباحاً - ٥ مساءً"; the table under it (store settings) and the About page say Sat–Thu 09:00–17:00, Friday closed. Contact day names show in English ("sunday").
3. **Terms §6 returns:** "تخضع المرتجعات لسياسة الإرجاع المعروضة في الإعدادات" (template text pointing at a policy that isn't shown anywhere). The account pages allow a return request within 14 days of delivery; the terms never say so.
4. Privacy says "the last-updated date appears above", but the page shows no date. Terms has its own language switch, print button and table of contents, and no `<h1>`; privacy has none of these. The two pages look unrelated.
5. Contact: "رقم هاتف آخر" label (same P2.4 key regression as checkout/settings). The FAQ block shows with a search box and "لا توجد منتجات مطابقة" because there are no FAQs.
6. Contact copy is about "bulk orders… powering your project" (template sales text); title "اتصل بالمبيعات".

**Track order**
7. **Loose lookup:** matches any order whose id *contains* the typed text and whose phone *contains* the typed digits (min 3 and 6 chars), so short guesses can return someone else's order status. Phone format isn't normalised (a `+249…` entry won't find a `09…` order).
8. Result shows the raw status code (`PENDING`) and nothing else; no page title; English-style plain form; the phone number goes into the URL.

**SEO**
9. **`robots.txt` blocks `/_next/`**, which stops Google loading the site's CSS and JS (pages render unstyled for the crawler). It also lists `/shop` (doesn't exist) and allows `/login` / `/register` (both `noindex`).
10. Sitemap includes `/login` and `/register` (noindex); category URLs use English names (`?category=Refrigerators`) and include empty categories.
11. Category pages: English title on the Arabic site ("Refrigerators | المنتجات"), no canonical, same description as all products. `/products`, `/contact`, home and `/track-order` have no canonical.
12. **No share image (`og:image`)** on home, about, contact, privacy, terms, while the card type is `summary_large_image`.
13. `/offline`, 404 and `/track-order` are indexable and reuse the home title/description.
14. Several files fall back to `https://essamnasr.com` (old domain) instead of the shared site-url helper. Harmless today because the env var is set, but wrong if it ever isn't.

**PWA**
15. Manifest name "Essam El-Din Nasr Electrical Tools" / "Essam Tools" (brand rule: Himmat leads), English-only description. The 512 icon is declared `any maskable` but has transparent rounded corners and the bolt touches the safe-zone edge, so Android crops it; a maskable SVG exists but isn't used.
16. Service worker and offline page are fine (navigation fallback only, no stale caching).

## Plan (one PR, `rebuild/p2-7-content`)

- **About:** remove the stats block (or keep only product count — owner choice); no made-up years.
- **Contact:** heading "ساعات العمل" with Arabic day names from store settings (no fixed text); own phone label; hide the FAQ block when there are no FAQs; plain, honest copy (title "تواصل معنا").
- **Terms/Privacy:** one shared layout (h1, last-updated date, no extra switch/print/TOC); returns section states the real policy (owner to confirm).
- **Track order:** exact match on the 8-char order ref (ends-with on the id) + phone in any Sudan format (`phoneVariants`), test-first; result card with Arabic status, date and total; POST via server action so the phone isn't in the URL; title; `noindex`.
- **SEO:** robots without `/_next` block or `/shop`, disallow auth/account/checkout; sitemap without auth pages, category URLs only for categories with active products; Arabic category titles + canonical on listing pages; canonicals on home/contact/products; `noindex` on offline/404/track-order; one site-url helper everywhere.
- **Share image:** `opengraph-image` (1200×630, Himmat bolt + name + shop label) generated with `next/og` at the app root.
- **PWA:** manifest Himmat-led (Arabic name, `lang: ar`, `dir: rtl`), separate full-bleed maskable PNG.
