# P0.4 App shell — audit (2026-10-04)

Scope (roadmap): navbar, footer, page layouts, theme toggle, RTL/LTR, language switch, loading/error/not-found states. Admin shell is P3.1.

## Findings

| # | Sev | Finding | Where |
|---|---|---|---|
| S-01 | High | Navbar + Footer are imported and placed by ~18 pages individually (each wraps its own `<main>` and sets `dir` again); `<header>`/`<nav>` end up inside `<main>`, pages drift (login/register have none), and every shell change touches 18 files. | `src/app/*/page.js`, `NotFoundClient`, `OrderConfirmationClient` |
| S-02 | High | Root `loading.js` runs for every route incl. admin/POS, reads store branding from the DB just to show a placeholder, and makes Next stream before `notFound()` → 404 pages (e.g. `/styleguide` on production) return HTTP 200. | `src/app/loading.js` |
| S-03 | High | Shared accessibility failures on every page (Lighthouse `link-name` ×2, `button-name` ×2): the cart is an icon `<Button>` nested inside a `<Link>` with no accessible name (invalid interactive nesting); the logged-out "Login" button is also a `<Button>` inside a `<Link>`. | `Navbar.js:212, 391` |
| S-04 | Medium | Footer social icons link to placeholder `https://facebook.com`, `twitter.com`, `instagram.com`, `linkedin.com` with no labels, while store settings already have `facebookUrl` / `instagramUrl`. | `Footer.js:48-58`, `prisma/schema.prisma:599-600` |
| S-05 | High (perf) | `src/lib/translations.js` (135 KB raw / 38 KB gzip, AR+EN, store + admin) is imported by 60 client components, so every page ships the whole dictionary. | `src/lib/translations.js` |
| S-06 | Medium | Navbar height animates between 72px and 60px on scroll (layout jump on every page) and pages compensate with their own top padding. | `Navbar.js:~300` |
| S-07 | Medium | Root `error.js` renders Navbar + Footer + framer-motion inside the error boundary; if the error came from the shell itself the boundary fails again. | `src/app/error.js` |
| S-08 | Low | Many physical direction classes in the shell (`ml-/mr-/left-/right-`, `isRTL && "flex-row-reverse"` instead of logical properties). | `Navbar.js`, `Footer.js` |
| S-09 | Low | Footer links are uppercase/`tracking-widest` 10–11px black-weight text (hard to read, odd in Arabic). | `Footer.js` |
