# P0.1 Local dev environment

## Found while smoke testing

Smoke run: Playwright against `npm run dev` (webpack) on seeded `store_dev`, as anonymous, `admin@powerstore.com` and `customer@example.com`. The dev machine has 3.2 GB RAM, so the run was cut short by memory pressure; pages not listed were not reached.

- **Fixed in P0.1:** CSP `script-src` had no `'unsafe-eval'`, so webpack dev chunks never ran — no hydration, and login was impossible in dev ("Evaluating a string as JavaScript violates the following Content Security Policy directive"). `next.config.mjs` now adds `'unsafe-eval'` in development only; pinned by `tests/unit/config/csp.test.ts`.
- `/about` (and any page rendering shipping zones): "Only plain objects can be passed to Client Components from Server Components. Decimal objects are not supported." — `ShippingZone.shippingCost` is passed as a Prisma `Decimal`.
- `/`, `/products/[slug]`: `/_next/image` returns 500 for `images.unsplash.com` seed images; one 404 resource on `/` and `/products`.
- `/admin`: browser error "Internal Next.js error: Router action dispatched before initialization." and the root error boundary fired (digest 1243792255).
- Under load the Prisma pg pool logs "timeout exceeded when trying to connect" / "Connection terminated due to connection timeout"; `/admin` took 2.1 min and `/admin/inventory` 3.2 min in dev.
- `next dev` restarts itself ("Server is approaching the used memory threshold") every few pages on this machine; `/contact` timed out during one restart.
- Not reached (memory): `/admin/orders`, `/admin/accounting` and the other admin modules, `/pos`, customer account pages. Re-run on a larger machine (e.g. Codespaces) in P0.2.
