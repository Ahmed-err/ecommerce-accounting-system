# P2.1 Home — audit and build (2026-10-05)

## Audit (live www.himmat.store)

| # | Sev | Finding |
|---|---|---|
| H-01 | High | Hero showed stock placeholder banners ("LED lighting", solar, cables) because the Banner table is empty; one rendered as a black box. The shop sells home appliances. |
| H-02 | High | "Partner brands" strip listed made-up companies (SafeWire, LumiSmart, PowerPro…). |
| H-03 | High | Product cards (home and listing) started at opacity 0 and only appeared when scrolled into view: a ~600 px blank gap in full-page renders and for anything that doesn't scroll. |
| H-04 | Medium | Categories showed two-letter placeholders ("ال") instead of photos. |
| H-05 | Medium | About teaser used stock solar-panel / electrician photos (the shop doesn't sell solar). |
| H-06 | Low | Product cards showed English category names on the Arabic page (public data dropped `nameAr`). Duplicate skip link; structured data used a stale fallback URL. |

Not changed (owner content): trust badges claim free delivery, certified warranty, secure payment, 24/7 support — confirm these are true.

## Decision (user)

Light 3D + scroll animations: CSS 3D tilt on cards, hero products in layered depth with pointer/scroll parallax, scroll reveals. No WebGL library.

## Built

- `HomeHero`: real products from three different top categories as floating cards (depth parallax with `DepthStage`, tilt with `Tilt3D`, gentle float); headline + real product count and top brands; first photo has priority for LCP.
- Admin banners show under the hero only when the admin has created some (production has none); stock fallback removed.
- `BrandsMarquee`: real brands from `Product.brand` with product counts, each linking to search; static list when motion is reduced.
- `CategoriesStrip`: 8 top categories in a grid, cover photo from one of their products, product count, 3D tilt.
- `motion.css`: `.reveal` / `.reveal-stagger` use native scroll timelines (`animation-timeline: view()`), only with `prefers-reduced-motion: no-preference`; unsupported browsers just show the content. Product cards no longer start hidden.
- About teaser without stock photos; section order: hero → categories → products → brands → trust → offer → about → newsletter.
- Catalog search also matches `brand`.

Motion cost: ~2 KB CSS + two small client helpers; no new dependencies.
