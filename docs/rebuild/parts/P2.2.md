# P2.2 Listing & search

## Audit (live www.himmat.store/products, 2026-10-06, desktop 1366 + phone 390)

Bugs
1. **Free orders:** checkout rejects only `price < 0` (`src/app/actions/catalog.js` checkout loop), so the 106 products at price 0 can be ordered for 0. Cards show "0 ج.س" with an active cart button.
2. **RTL order is reversed** by `isRTL && "flex-row-reverse"` on top of `dir="rtl"`: breadcrumb reads المنتجات / الرئيسية, pagination puts "السابق" on the left, the sort tabs and stock checkbox are mirrored twice.
3. **Phone:** the quick-view overlay covers every card image with a dark tint, so tapping the photo opens quick view instead of the product. Cards are one per row (136 products = very long scroll).
4. Every filter change runs `router.replace` **and** `router.refresh`, so the page is fetched twice.
5. JSON-LD ItemList uses `/products/<id>` and the request host instead of the slug + `getAbsoluteSiteUrl()`.

Missing
6. No **brand filter** (brand field added in P1.2).
7. Category list shows all 40 rows expanded; long sidebar, longer phone sheet.

Accessibility (P0.3 carry-over: aria-hidden-focus 12, label 12, heading-order 1)
8. Price inputs have no label (both placeholders read "السعر"); search box has no label; clear-search button has no name.
9. Hidden duplicate controls focusable; filter headings are h3 under h1 (skips h2).

Style
10. Search box hard-codes zinc colours instead of the `Input` component. Six sort tabs wrap into two rows on phone.

## Plan

1. ~~Zero price~~ — **user, 2026-10-06: leave as is**; the admin will add prices. Checkout still accepts price 0 (owner aware).
2. **Brand filter:** `brand` URL param in `getCatalogProducts` (exact match, with test); brand list with counts in the filter panel; home brand chips link to `?brand=`.
3. **Category tree:** top categories only; the active parent expands to its children.
4. **RTL:** remove the double reversals; use logical properties (`ms-/me-`, `start/end`).
5. **Phone:** 2 cards per row; no quick-view overlay on touch (button stays on hover for desktop); filter button shows a text label + active-filter count; sort becomes a native `<select>` on phone, tabs on desktop.
6. **Speed:** drop `router.refresh()`; JSON-LD uses slug + site URL.
7. **A11y:** labels for search and price inputs (من / إلى), named clear button, filter headings h2, active-filter chips with remove buttons.

Out of scope: product page (P2.3), header search (P2.7).
