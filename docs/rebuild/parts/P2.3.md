# P2.3 Product page

## Audit (live, 2026-10-06, desktop 1366 + phone 390)

1. **Phone:** description/specs tab panel was 823px wide (`flex-none` in a row-flex Tabs root) and clipped by `overflow-x-hidden` — most of the text was unreadable.
2. Tabs, related and recently-viewed sections started at opacity 0 (framer `whileInView`) → large blank gap until scrolled.
3. Category label and breadcrumb in English ("MICROWAVES") on the Arabic page (no `nameAr`).
4. Price block forced `dir="ltr"` → left-aligned on the Arabic page; unit shown as "pcs".
5. Gallery thumbnails and related rail reversed twice in RTL; redundant "3 صور" counter and hint text.
6. Zero reviews showed "0.0 ☆☆☆☆☆ (0 تقييم)".
7. A11y: four quantity buttons without names (P0.3 button-name).
8. Canonical used `AUTH_URL`/request host and the slug as typed; one product reachable by id, sku or name had several canonicals.
9. Unknown/hidden product: 200 + noindex, but also the root "index, follow" tag.

## Done

All of the above fixed; canonical is always `<site>/products/<id>`; missing product metadata sets `robots: noindex`.

Accepted: the not-found status stays 200 (streamed under `(store)/loading.js`, Next marks it `noindex`; a real 404 would need a DB check in `proxy`). Trust tiles (free returns, warranty, 100% original) await owner confirmation with the home trust badges.
