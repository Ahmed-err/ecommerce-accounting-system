# P0.4 App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One shared, accessible, lighter store shell — route group layout with skip link, sticky 64px header, refined footer, correct loading/error/404 states — and only the current language's text sent to the browser.

**Architecture:** Store pages move into `src/app/(store)/` whose `layout.js` renders `SiteHeader` + `<main id="content">` + `SiteFooter`. The dictionary splits into `src/lib/i18n/{ar,en}.js`; the root layout passes the current language's dictionary into `LanguageProvider`, and client code reads it with `useT()` (codemod). Header is split into four focused files; footer is rebuilt from store settings.

**Tech Stack:** Next.js 16 App Router (route groups, `loading.js`, `not-found.js`, `error.js`, `global-error.js`), React 19, Tailwind v4, Base UI shadcn wrappers, next-auth, Vitest + Testing Library, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-04-p0-4-app-shell-design.md` (read with this plan). Mockups: https://claude.ai/artifact/4RHEHcqGxih3z9BDEPAUuY boards 5–6.

## Global Constraints

- URLs must not change; route groups only.
- Refine, don't redesign: boards 5–6 are the target; no new visual language.
- Header: `sticky top-0`, height `h-16` (64px), no height animation; every label `whitespace-nowrap`; only search shrinks (`flex-1 min-w-0 max-w-[360px]`).
- No `<Button>` (or any interactive element) inside `<Link>` in the shell. Every icon-only control has an `aria-label`.
- Logical CSS only in shell files (`ms-/me-/ps-/pe-/start-/end-/inset-inline-*`); no `isRTL ? … flex-row-reverse` branches.
- Footer columns: Shop (`/products`, `/cart`, `/about`) · Help (`/track-order`, `/contact`, `/privacy`, `/terms`) · Contact (settings phone/email/address). Socials only from settings `facebookUrl`, `instagramUrl`, `whatsappUrl`, `tiktokUrl`. Keep `<DeveloperCredit />` in the bottom bar.
- No `"use client"` module may import `@/lib/translations`; client code uses `useT()`.
- Admin, POS, `orders/[id]/invoice`, `offline`, `styleguide`, `settings`, `my-orders` stay outside `(store)`.
- No database or schema change. Commit after every task; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Language switch** (`setLang("en")` then `router.refresh()`): text must follow — `useT()` must read the provider's *prop* each render, never a stale copy in state. Test in Task 1.
2. **Store settings with empty or whitespace values** (no phone, blank social URLs, `"  "` shop name): nothing renders empty, no `href=""`. Tests in Tasks 4 and 8.
3. **Cart count edge values** (0, 1, 10+ → "9+", cart not loaded yet): accessible name stays correct and no badge flashes `0`. Test in Task 7.
4. **Signed-in staff vs customer vs guest** in the header (POS/Admin links only for staff, Admin only for ADMIN/MANAGER, Login link only for guests). Test in Task 7.
5. **Unknown URL and server error inside the shell**: 404 status + header/footer present; error page renders without the header crashing it. Tests in Tasks 6 and 9.

```js
#!/usr/bin/env node
// P0.4 codemod: client components read the dictionary via useT() instead of importing both languages.
// Usage: node scripts/codemods/use-t.mjs [--write] <files…>
import fs from "node:fs";
import { pathToFileURL } from "node:url";

const LOOKUP = /^(\s*)const (\w+) = translations\[[^\]]+\](?:\s*\|\|\s*translations(?:\.\w+|\[['"]\w+['"]\]))?;\s*$/m;
const IMPORT_ONLY = /^import \{\s*translations\s*\} from "@\/lib\/translations";\n/m;
const IMPORT_WITH_TC = /^import \{\s*translations,\s*translateCategory\s*\} from "@\/lib\/translations";$/m;
const LANG_IMPORT = /^import \{([^}]*)\} from "@\/context\/LanguageContext";$/m;

export function transformUseT(src) {
  if (!src.includes('"use client"') || !LOOKUP.test(src)) return { code: src, changed: false, manual: [] };
  let code = src.replace(LOOKUP, "$1const $2 = useT();");
  code = code.replace(IMPORT_WITH_TC, 'import { translateCategory } from "@/lib/i18n/translate-category";');
  code = code.replace(IMPORT_ONLY, "");
  if (LANG_IMPORT.test(code)) {
    code = code.replace(LANG_IMPORT, (whole, names) =>
      names.split(",").map((n) => n.trim()).includes("useT") ? whole : `import {${names.replace(/\s*$/, "")}, useT } from "@/context/LanguageContext";`
    );
  } else {
    const lines = code.split("\n");
    const lastImport = lines.reduce((acc, l, i) => (/^import /.test(l) ? i : acc), -1);
    lines.splice(lastImport + 1, 0, 'import { useT } from "@/context/LanguageContext";');
    code = lines.join("\n");
  }
  const manual = [...code.matchAll(/\btranslations(?:\.\w+)+|\btranslations\[[^\]]+\][\w.]*/g)].map((m) => m[0]);
  return { code, changed: true, manual };
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const write = process.argv.includes("--write");
  for (const file of process.argv.slice(2).filter((a) => !a.startsWith("--"))) {
    const { code, changed, manual } = transformUseT(fs.readFileSync(file, "utf8"));
    if (!changed) { console.log(`skip   ${file}`); continue; }
    if (write) fs.writeFileSync(file, code);
    console.log(`${manual.length ? "MANUAL" : "ok    "} ${file}${manual.length ? "  " + manual.join(", ") : ""}`);
  }
}
```
Note: in the `LANG_IMPORT` replacement the first test expects `import { useLanguage, useT }` — trim the captured names and rebuild as `import { ${[...names, "useT"].join(", ")} } …` if the spacing differs; the test is the contract.

- [ ] **Step 3: Implement `scripts/check-client-bundle.mjs`**
```js
#!/usr/bin/env node
// Fails if UI dictionary text is bundled into client JS (P0.4: only the current language travels, via the layout).
// Run after `next build`: node scripts/check-client-bundle.mjs
import fs from "node:fs";
import path from "node:path";
import { pathToFileURL } from "node:url";
import ar from "../src/lib/i18n/ar.js";
import en from "../src/lib/i18n/en.js";

export function pickSamples(count = 10) {
  const pick = (dict) =>
    Object.values(dict)
      .filter((v) => typeof v === "string" && v.length >= 24 && !/[{}<>]/.test(v))
      .sort((a, b) => b.length - a.length)
      .filter((_, i) => i % 7 === 0)
      .slice(0, count);
  return [...pick(ar), ...pick(en)];
}

function walk(dir) {
  return fs.existsSync(dir)
    ? fs.readdirSync(dir, { withFileTypes: true }).flatMap((e) => {
        const f = path.join(dir, e.name);
        return e.isDirectory() ? walk(f) : f.endsWith(".js") ? [f] : [];
      })
    : [];
}

export function findDictionaryLeaks(dir, samples) {
  return walk(dir).filter((f) => {
    const s = fs.readFileSync(f, "utf8");
    return samples.some((x) => s.includes(x) || s.includes(JSON.stringify(x).slice(1, -1)));
  });
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const leaks = findDictionaryLeaks(".next/static/chunks", pickSamples());
  if (leaks.length) {
    console.error(`Dictionary text found in client chunks:\n${leaks.join("\n")}`);
    process.exit(1);
  }
  console.log("client bundle: no dictionary text");
}
```

```js
#!/usr/bin/env node
// P0.4: pages inside (store) get Navbar/Footer/<main> from the layout; strip them from the page.
import fs from "node:fs";
import { pathToFileURL } from "node:url";

export function stripShell(src) {
  let code = src
    .replace(/^import (Navbar|Footer) from "@\/components\/(Navbar|Footer)";\n/gm, "")
    .replace(/^\s*<(Navbar|Footer)\s*\/>\n/gm, "");
  // First <main …> becomes <div …> without min-h-screen / dir; matching close tag too.
  code = code.replace(/<main\b([^>]*)>/, (whole, attrs) => {
    const cleaned = attrs
      .replace(/\sdir=\{[^}]*\}|\sdir="[^"]*"/, "")
      .replace(/className="([^"]*)"/, (m, c) => `className="${c.split(/\s+/).filter((x) => x && x !== "min-h-screen").join(" ")}"`)
      .replace(/\sclassName=""/, "");
    return `<div${cleaned}>`;
  });
  code = code.replace(/<\/main>(?![\s\S]*<\/main>)/, "</div>");
  return { code, changed: code !== src };
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  for (const file of process.argv.slice(2)) {
    const { code, changed } = stripShell(fs.readFileSync(file, "utf8"));
    if (changed) fs.writeFileSync(file, code);
    console.log(`${changed ? "stripped" : "same    "} ${file}`);
  }
}
```

```ts
import { expect, test } from "@playwright/test";

test.describe("store shell", () => {
  for (const path of ["/", "/products", "/cart", "/login", "/track-order", "/about", "/privacy"]) {
    test(`${path} renders inside the shell`, async ({ page }) => {
      const res = await page.goto(path);
      expect(res?.status()).toBe(200);
      await expect(page.locator("header").first()).toBeVisible();
      await expect(page.locator("main#content")).toHaveCount(1);
      await expect(page.locator("footer").first()).toBeVisible();
    });
  }

  test("unknown URLs return 404 inside the shell", async ({ page }) => {
    const res = await page.goto("/this-page-does-not-exist");
    expect(res?.status()).toBe(404);
    await expect(page.locator("header").first()).toBeVisible();
  });

  test("skip link moves focus to the content", async ({ page }) => {
    await page.goto("/products");
    await page.keyboard.press("Tab");
    await expect(page.locator('a[href="#content"]')).toBeFocused();
    await page.keyboard.press("Enter");
    await expect(page.locator("main#content")).toBeFocused();
  });
});
```
